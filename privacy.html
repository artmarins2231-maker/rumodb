Política de Privacidade

Última atualização: agosto de 2026

Esta política explica quais dados o Traja coleta, por que coleta, e como você pode controlar suas informações, em conformidade com a LGPD (Lei Geral de Proteção de Dados).

1. Quais dados coletamos

  • Dados de cadastro: nome, e-mail, senha (armazenada com hash PBKDF2 + salt, nunca em texto puro) e cidade de origem, se informada.
  • Dados de uso: viagens salvas como favoritas, buscas realizadas (orçamento, destino, datas) para gerar os resultados.
  • Dados técnicos: registros de login (data/hora) para segurança da conta.
  • Não coletamos dados de pagamento diretamente — hoje o Traja não processa cartão de crédito nem dados bancários.

2. Por que coletamos

  • Para permitir login e salvar suas viagens favoritas entre sessões.
  • Para gerar as sugestões de destino com base no orçamento informado.
  • Para prevenir abuso (ex.: limite de tentativas de login).
  • Nunca vendemos ou compartilhamos seus dados com terceiros para fins de publicidade.

3. Onde os dados ficam armazenados

Os dados de usuários e logins ficam em um banco de dados externo, controlado pelo servidor do Traja (server.js), fora do código público do site. O acesso ao painel administrativo é protegido por chave de administrador.

4. Seus direitos (LGPD)

  • Solicitar uma cópia dos dados que temos sobre você.
  • Solicitar a correção de dados incorretos.
  • Solicitar a exclusão total da sua conta e dos dados associados.
  • Revogar consentimento a qualquer momento, encerrando o uso do serviço.

Para exercer qualquer um desses direitos, entre em contato pelo e-mail indicado no rodapé do site.

5. Cookies e armazenamento local

Usamos armazenamento local do navegador (localStorage) para lembrar seu idioma preferido, o tema (claro/escuro) e sua sessão de login. Não usamos cookies de rastreamento de terceiros nem publicidade direcionada.

6. Alterações nesta política

Podemos atualizar esta política periodicamente. Mudanças relevantes serão indicadas pela data de "última atualização" no topo desta página.

7. Contato

Dúvidas sobre privacidade e dados pessoais podem ser enviadas para o e-mail de contato indicado no rodapé do site.
